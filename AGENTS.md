# Verification commands

- Unit tests: `./mvnw test`
- Targeted mutation feedback: `./mvnw -Pmutation-testing test-compile pitest:mutationCoverage`

# Mutation testing: two layers

- Layer 1 uses framework-generated mutants from PITest. Layer 2 uses
  requirement-driven semantic mutants generated by the agent.
- Run normal verification first, then Layer 1 for configured changed code. Add
  Layer 2 only for changed high-risk behavior; do not combine the two result
  sets into one mutation score.

## Layer 1: framework-generated mutants (PITest)

- Run the normal tests first, then the mutation profile after changing JMS configuration, listener behavior, email rendering, or their tests.
- Treat `NO_COVERAGE` as a reachability gap and `SURVIVED` as an assertion gap. A configuration context merely starting is not proof that the listener factory and converter honor the producer contract.
- For each meaningful survivor, add a test that passes on the original and fails on the mutant. Do not add brittle assertions solely to increase the percentage.
- Keep the score advisory until the baseline stabilizes; reject new meaningful wiring survivors before adopting a global numeric gate.

## Layer 2: agent-generated semantic mutants

- After normal tests and PITest, generate one to three requirement-driven semantic mutants for changed JMS wiring, producer compatibility, deserialization, rendering, or delivery behavior.
- Prefer plausible configuration cleanup, alias removal, ordering, mapping, and integration misunderstandings over operators PITest already covers. State the violated contract and observable difference for each patch.
- Apply candidates only in a disposable copy or worktree. Require compilation; compiler failures are invalid, not killed. Run the smallest relevant green test target.
- Review survivors for equivalence and requirement validity. For a meaningful survivor, add a contract test that passes on the original and fails on the frozen mutant; a Spring context merely starting is not sufficient proof.
- Keep the challenge bounded and report killed, survived, invalid, and equivalent candidates separately.
